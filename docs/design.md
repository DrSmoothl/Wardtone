# Wardtone 界面规范

戍声是一款桌面语音工作台。界面围绕资源、语音包和替换记录组织操作。提供三套具有独立视觉风格的终端界面，并保留安静紧凑的经典主题。

## 布局与排版

四套主题共享语义内容，以不同的外壳组织界面：

- **可露希尔**：顶部任务栏、86 px 页面工具栏、多窗口桌面。工作台的播控窗口与资源监视器并排，语音包呈磁带卡片。窗口有偏移阴影与小幅错位，频道用实体按键切换。
- **卫戍终端**：96 px 窄导航轨、94 px 工具栏、网格和细线框架。宽屏语音库的频道位于左侧，记录位于右侧；窄屏移至列表上方。
- **乌萨斯**：216 px 深青机架、100 px 浅色工具栏、米色金属面板、锈红标记与机械仪表。导航、资源仪表和正文分别使用独立的前景色，浅色正文保持可读。
- **经典**：216 px 侧栏、52 px 工具栏、紧凑列表和单列信息流。

内容留白随宽度在 20–30 px 之间变化。制作页在宽屏采用元数据与轨道双面板，内容宽度小于 880 px 时收为单列。短窗口隐藏乌萨斯装饰铭牌，保留全部导航与连接入口。
正文使用系统字体，包括 SF Pro Text、苹方与 Segoe UI。可露希尔标题使用得意黑，英文标题和读数使用 Chakra Petch；卫戍终端使用 Rajdhani，乌萨斯使用 Barlow Condensed。所有附加字体随应用发布。数字、语音编号、摘要和操作编号使用随包发布的 IBM Plex Mono，数字右对齐。正文 14/20 px，辅助文字 13/18 px，说明 12/16 px，分组及工具栏标题 16/22 px，首次设置标题 22/28 px。终端的资源仪表使用 32–46 px 读数，经典保留 22/26 px。展示标题可放大至 46 px。

按钮高度为 28、32、36 px；图标 16 px、线宽 1.6，空状态图标 20 px；开关 30×18 px，勾选框 16 px。圆角使用 4、5、7、10、14 px。列表、表格和分组保持清晰的内容层次。经典以发丝线分隔；终端可以使用切角、双层描边、偏移投影、网格与工业标记，但不能遮挡正文或缩小操作区域。

## 色彩与外观

主题的色彩、字体、尺寸和资源定义在 `src/renderer/themes`，`profiles/arcade.css`、`tactical.css`、`industrial.css` 分别负责结构与控件风格。所有页面只消费语义变量，主题切换时一次更新根节点的完整 token，浮层与播放器同步继承。`tokens.css` 保留公共动效、阴影和字体栈。颜色使用 OKLCH。

| 主题                     | 视觉语言                                                       | 外观     |
| ------------------------ | -------------------------------------------------------------- | -------- |
| “全能的”可露希尔（默认） | 蓝紫桌面窗口、玫红主操作、青色信号、黄色标记、扫描线与窗口拼贴 | 深色     |
| 卫戍协议终端             | 青绿战术屏、琥珀信号、等高线、细网格与切角框架                 | 深色     |
| 乌萨斯齐心团             | 米色金属面板、深青机架、锈红海报与机械仪表                     | 浅色     |
| 经典                     | 中性表面、紧凑列表、五种可选强调色                             | 跟随系统 |

失败与警告保持独立的语义色，不能借用装饰色表达状态。文字必须在背景图片之外或有足够的不透明底色。主题预览使用与真实界面相同的 token，展示对应导航结构。25 个本地游戏素材参与窗口边框、按钮、频道、仪表、身份标识和背景，来源见资源清单。

界面大小提供 100%、112%、125%，由 Electron 对整个页面统一缩放，菜单和对话框保持一致。减少动态效果由系统设置与应用开关共同控制。

## 共享控件

所有共享控件位于 `src/renderer/components/ui.tsx`。

| 控件       | 契约                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------ |
| Button     | 主、次、轻、危险、实心危险五类；一个操作组最多一个主按钮，位于右侧；图标按钮有读屏名称及延迟提示 |
| Select     | 自绘菜单锚定触发器下方，支持方向键、Home、End、Enter、Escape；选中项有勾号                       |
| Segmented  | 少量互斥选项直接显示；中性滑块选中态，支持左右键；不使用强调色底                                 |
| Checkbox   | 支持选中、未选与部分选中；批量操作显示已选数量                                                   |
| Switch     | 用于立即保存的偏好；点击关联标签亦可操作                                                         |
| Slider     | 音量与试听进度共用；有可访问名称和方向键操作                                                     |
| Help       | 右侧 `i`；悬停 450 ms 展开，指针可移入；点击固定，Escape 或外部点击关闭                          |
| ScrollArea | 透明轨道与细滑块覆盖内容边缘，保留滚轮、触控板及键盘滚动                                         |
| Modal      | 固定标题与关闭按钮；正文及底部操作在同一可滚动流中；焦点约束与返回                               |
| Disclosure | 用于日志、错误细节等渐进披露，不使用默认浏览器三角样式                                           |

文本字段统一描边、背景、字号与焦点环。网页内不使用默认 select、checkbox、range、audio controls 或浏览器 alert/confirm。选择文件与保存位置使用系统文件选择器；业务确认使用共享 Modal。

## 页面

- **工作台**：终端的操作台提供进入语音库和新建入口，资源监视器展示实际扫描数量；卡片显示包名、版本、作者、条目数和操作。经典保持摘要与列表。
- **语音库**：先按终端播报、公共音效、背景音乐分类。终端以频道按键筛选资源；经典使用共享下拉框。搜索、多选、排序与批量入口共用业务逻辑，列表显示用途、编号、主题/语言、时长及替换状态。播放器在滚动区下方独立占位，提供循环试听，不覆盖末条。
- **制作**：元数据面板与轨道装配面板分开。宽屏并排，窄屏上下排列；保存区位于两者之后。单条语音的模式和处理参数进入主题化对话框。
- **备份与恢复**：按事务展示来源、时间、状态与文件数；恢复需要明确确认。
- **日志**：按时间展示等级与事件，点击展开参数、摘要及完整操作编号。
- **设置**：外观、偏好与连接、数据与诊断三个标签页。外观顶部为四套主题预览，支持鼠标和方向键切换；其他偏好使用分组列表。主题选择保存期间保留焦点。
- **首次设置**：选择本机或模拟器、定位目录、选择连接。只显示当前需要的字段。

普通标题下不重复写解释。含义不易判断的操作使用右侧信息弹层；缺失资源、错误原因、未保存状态和正在执行的操作直接可见。

## 反馈与动效

悬停、按下使用 120 ms；选择、菜单与开关使用 180 ms；对话框使用 240 ms，曲线为 `cubic-bezier(.2,0,0,1)`。页面切换使用 5 px 入场位移，可露希尔按键使用 1 px 下压。主题切换保留业务组件和草稿；没有循环装饰动画。

加载超过 300 ms 才显示进度，显示后至少保留 400 ms。完成提示位于右下角，4 秒消失，指针移入时暂停。错误持续显示并提供细节和复制诊断；未知数量显示破折号。

关闭窗口和退出菜单均先检查当前操作与草稿。未保存时可继续编辑、舍弃并退出或保存并退出；操作尚未结束时显示操作名称。没有未保存内容时直接退出。

## 图标

英文名 Wardtone 结合守卫与声音。图标将城垛和声波组成 W 形轮廓，使用墨蓝底与白色主体。主图使用透明边距，产品界面、Dock 和安装包共用同一标识。

## 可访问性与验证

提供跳到主要内容的入口、明确的焦点环、表单标签与图标读屏名称。对话框关闭后恢复焦点，选择控件可用键盘操作。验证首次设置、语音库、制作、设置、菜单、试听和退出确认；检查缩放后布局、真实数据与配置持久化。
