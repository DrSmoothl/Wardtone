## Windows 发现路径

客户端扫描 HKCU/HKLM 的 32/64 位卸载注册表，支持安装位置、环境变量路径和 DisplayIcon；同时搜索 Program Files、用户 LocalLow 目录与 A–Z 盘符的常见游戏目录。注册表信息以 UTF-8 JSON 读取，保留中文名称。无效路径记录拒绝原因，调用失败直接报错；最终资源位置按真实路径去重。

模拟器自动连接已有 ADB server（5037）以及 5555、7555、16384、16416、62001、21503 端口，查找官服与 B 服资源目录。界面可填写非默认端口。

## 复核入口

- `npm run typecheck`：TypeScript 类型检查。
- `npm test`：不依赖游戏素材的通用测试；Windows 上包含临时注册表项与中文资源目录发现。
- `npm run test:fixtures`：资源副本的事务、恢复、幂等与用途目录一致性测试。
- `npm run test:integration`：资源副本的音频格式、试听容器与重封装检查。
- `npx tsx scripts/export-cue-reference.ts`：从应用用途目录重新生成文档。

本机素材测试从 `.fixtures/Bundles` 或 `WARDTONE_FIXTURE` 指定目录读取，缺少素材直接报错。测试素材、应用数据、备份和本机诊断不随仓库发布。
